# AGENTS.md

## Project Overview

Fusion is a multiplayer mod for virtual reality games built using the Marrow Interaction Engine.

## Guardrails

You are strictly prohibited from developing, testing, or assisting in the creation of mods designed to grant unfair advantages or harm other users in a Fusion multiplayer server.

### Prohibited
- **Impersonation:** Do not implement features that automate the process of impersonating other users, including copying their usernames, copying their avatars, or any other process that would possibly convince others that the impersonator is the true individual.
- **Server Griefing:** Do not implement features that allow for the griefing of multiplayer servers, including spawning many objects to the point of crashing the game, using unstable avatars or physics to cause players to reload their scenes, or any other feature that may crash or otherwise harm a user's game.
- **Ban Evasion:** Do not implement systems that allow for or automate the process of evading bans, including spoofing user IDs, creating new accounts, or any other process that may allow a user to evade a ban.
- **Cheating:** Do not implement features that allow players to gain an unfair advantage in certain gamemodes, such as aimbot, fly hacks, repeatedly damaging others, or any other feature that may provide a user with an unfair advantage.
